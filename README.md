# AI-EL5-09
# Kumpulan Proyek Kecerdasan Buatan (AI)

## 1. Pendahuluan

Repository ini berisi tiga proyek Kecerdasan Buatan (Artificial Intelligence/AI) yang dikembangkan untuk mendemonstrasikan berbagai pendekatan dalam menyelesaikan masalah menggunakan konsep dan teknik AI.

Ketiga proyek ini mencakup penalaran berbasis aturan, algoritma pencarian, dan sistem multi-agen.

Daftar proyek dalam repository ini adalah:

1. **Expert System** — Sistem berbasis aturan untuk mendiagnosis permasalahan komputer dan memberikan rekomendasi solusi.
2. **Search Algorithm** — Aplikasi penyelesaian labirin menggunakan algoritma pencarian, seperti Breadth-First Search (BFS) dan Depth-First Search (DFS).
3. **Multi-Agent System** — Sistem yang menggunakan beberapa agen untuk melakukan diagnosis, menghasilkan rekomendasi, dan mengoordinasikan proses pengambilan keputusan.

Setiap proyek disimpan dalam direktori terpisah agar kode program lebih mudah dipahami, dikembangkan, diuji, dan dipelihara.

## 2. Persyaratan

Perangkat lunak dan alat yang diperlukan untuk menjalankan proyek-proyek ini meliputi:

- Python versi 3.10 atau lebih baru (disarankan).
- Editor kode, seperti Visual Studio Code.
- Git untuk pengelolaan versi dan kolaborasi.
- Terminal atau Command Prompt untuk menjalankan program.

Tidak diperlukan pustaka Python tambahan apabila implementasi hanya menggunakan pustaka standar Python. Jika terdapat dependensi tambahan, persyaratan tersebut akan dijelaskan pada dokumentasi masing-masing proyek.

## 3. Cara Menggunakan

### Langkah 1: Mengunduh Repository

Jalankan perintah berikut pada terminal:

```bash
git clone <URL-repository>
```

Ganti `<URL-repository>` dengan alamat repository GitHub yang digunakan.

### Langkah 2: Membuka Direktori Repository

```bash
cd <nama-folder-repository>
```

### Langkah 3: Memilih Proyek

Masuk ke direktori proyek yang ingin dijalankan:

- `01_Expert_System`
- `02_Search_Algorithm`
- `03_Multi_Agent_System`

### Langkah 4: Menjalankan Program

Jalankan berkas `main.py` dari direktori proyek yang dipilih:

```bash
python main.py
```

Ikuti instruksi yang ditampilkan pada terminal.

## 4. Hasil

Repository ini mendemonstrasikan tiga pendekatan berbeda dalam menyelesaikan masalah menggunakan kecerdasan buatan.

- **Expert System:** Mengidentifikasi kemungkinan permasalahan komputer berdasarkan informasi yang diberikan pengguna dan aturan yang telah ditentukan.
- **Search Algorithm:** Menelusuri kemungkinan jalur dalam labirin untuk menemukan rute dari titik awal menuju titik tujuan.
- **Multi-Agent System:** Membagi proses penyelesaian masalah kepada beberapa agen yang menangani diagnosis, pemberian rekomendasi, dan koordinasi.

Ketiga proyek ini memberikan pemahaman praktis mengenai penalaran berbasis aturan, pencarian ruang keadaan, serta penyelesaian masalah melalui kolaborasi antaragen.
